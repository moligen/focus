🛡️ FOCUS: Integrated Network Security Ecosystem
FOCUS is a high-performance, hardware-backed penetration testing and network auditing platform. It merges the portability of ESP32, the intuitive interface of Android, and the global reach of Telegram into a single, modular security tool.

🚀 Core Features
📡 ESP32 Hardware Integration: Direct interaction with 2.4GHz radio for sniffing, packet injection, and captive portal manipulation.

📱 Android Command Center: Real-time visual data analysis and local control via Bluetooth/Wi-Fi, leveraging modern system UI capabilities.

🤖 Telegram Global Remote: Manage your device from anywhere in the world. Execute /scan or /attack commands and receive instant alerts.

🌐 Captive Portal Auditor: Automated testing of public network login pages to identify bypass vulnerabilities and credential leaks.

🧩 Modular Architecture: Easily add new exploit modules for Bluetooth, GPS tracking, or custom network protocols.

🛠️ System Architecture
The Agent (ESP32): The physical unit that stays on-site to handle low-level network tasks.

The Controller (Android): The local GUI for monitoring traffic and managing the ESP32 via BLE.

The Bridge (Telegram): The remote uplink for receiving data and sending commands globally.

📂 Project Structure

├── 🛰️ firmware/      # ESP32 C++/Arduino or MicroPython source code
├── 📱 mobile_app/    # Android application source (Flutter/React Native)
├── 🤖 bot/           # Telegram Bot integration scripts (Python)
└── 📑 docs/          # Technical documentation and setup guides
